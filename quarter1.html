Web Development Lessons

Lesson 1 - XHTML

eXtensible HyperText Markup Language (XHTML)

The “x” comes from XML or eXtensible Mark-up Language.

Though different from HTML, XHTML also uses the filename extension .html.

It is a stricter and cleaner version of HTML, aimed to replace HTML. All new browsers support XHTML.

Examples:

Proper Nesting:

<b><i>This text will appear in boldface and in italics</i></b>

Proper Tag Closing:

<p>XHTML requires proper closing of tags.</p>

Elements in Lowercase Characters:

<p>Elements should be written in lowercase.</p>

One Root Element:

<html>
    <head>
        <title>One Root</title>
    </head>
    <body>
        <!-- body part goes here -->
    </body>
</html>

Attributes in Lowercase Characters:

<img src="violetFlower.jpg" />

Quoted Values:

<hr width="200" />

Forbidden Attribute Minimization:

<hr noshade="noshade" />

Image Alternate Texts:

<img src="blackcat.jpg" alt="a picture of a black cat" />

Ampersands in URLs:

<a href="dataLibrary.php?page=12&style=green">link</a>

Contents within Block-Level Elements:

<body><div>Put a chunk of text here.</div></body>

Lesson 2 - HTML Lists

Used to specify lists of information. Three types of HTML lists:

  • Ordered List (ol)
  • Unordered List (ul)
  • Description List (dl)

HTML Tags:

TagDefinition
<ul>Unordered/bulleted list
<ol>Ordered/numbered list
<dl>Description/Definition list
<li>Line item

Ordered List Attributes:

AttributeDefinitionValues
typeType of numbering1, a, A, i, I
startNumber of first itemAny number

Unordered List:

Bullets: disc (round), circle (circular), square (square)

Definition List:

Uses <dt> for term and <dd> for definition.

Nested List:

You can nest lists inside <li> tags to create hierarchy.

Lesson 3 - HTML Tables

Tables organize data into rows and columns. Made up of <table>, <tr>, <td>.

Table Attributes:

AttributeDefinitionExample/Value
alignHorizontal alignment<table align="center">
backgroundBackground image<table background="smiley.jpg">
bgcolorBackground color<table bgcolor="violet">
borderBorder thickness<table border="2">
bordercolorBorder color<table bordercolor="yellow">
cellpaddingDistance inside cells<table cellpadding="2">
cellspacingDistance between cells<table cellspacing="2">
widthTable width<table width="800">

Row Attributes:

AttributeDefinition

valignVertical alignment
